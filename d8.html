English Grammar Practice

Some / Any / A / An
We use some in positive sentences. (There are some desks.)
We use any in negative sentences and questions. (There aren't any books. / Are there any chairs?)
We use a before consonant sounds. (There's a table.)
We use an before vowel sounds. (Is there an armchair?)
